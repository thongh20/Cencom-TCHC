🧠 Astrolabe — AI Semantic Search (App chính)
🔍 AI-powered semantic search across your Nextcloud
Tìm nội dung theo nghĩa (semantic), không chỉ từ khóa. Kết nối MCP Server để vector hóa và phân tích tài liệu bằng AI. Source: apps/astrolabe
📝 Semantic Search
Tìm kiếm across Notes, Files, Calendar, Deck, Mail, Contacts, News bằng ngôn ngữ tự nhiên: "họp tuần trước", "công thức gà".
🔎 Hybrid Search
Kết hợp Semantic (vector) + BM25 (keyword) + Hybrid để tối ưu kết quả. Thuật toán per-document.
📊 Vector Visualization
Trực quan hóa nội dung trong không gian 2D (PCA plot). Khám phá mối quan hệ ngữ nghĩa giữa các tài liệu.
🤖 Agent Chat
Chatbot AI với tool-calling (AgentLoop). Đọc tài liệu → trả lời có trích dẫn nguồn. Read-only by construction.
📋 Summary (Tóm tắt)
2 chế độ: text2text (văn bản) và analyze-images (multimodal — giữ nguyên bảng, biểu đồ, chữ viết tay).
🔗 Unified Search
Kết quả hiện trong thanh tìm kiếm toàn cục Nextcloud cùng kết quả truyền thống. SemanticSearchProvider implements IProvider.
📑 Citation (Trích dẫn)
Mỗi câu trả lời AI đều kèm nguồn trích dẫn (max 10 citations/turn). Trích dẫn link trực tiếp đến passage cụ thể.
🔄 Background Indexing
Tự động lập chỉ mục qua WebDAV + sync events. Webhook presets cho File, Deck, System-tag tạo chỉ mục realtime.

⚙️ 3 Thuật toán tìm kiếm
🔵 Semantic
Tìm theo nghĩa — so sánh vector embeddings. Kết quả dựa trên khoảng cách ngữ nghĩa, không cần khớp từ khóa.
🟡 BM25
Tìm keyword — thuật toán truyền thống, chính xác với từ khóa cụ thể. Tốt cho tên file, số điện thoại, mã…
🟣 Hybrid
Kết hợp cả 2 — re-rank kết quả semantic + BM25. Mặc định và được khuyến nghị.
  • Per-document keyword index: Dựa vào tag vector-index — file nào có tag = dùng keyword index
  • Server advertises: ["semantic", "bm25", "hybrid"] hoặc [] (vector sync off)
  • Client-side guard: SearchCapabilities kiểm tra server có hỗ trợ thuật toán không → UI chỉ hiện lựa chọn hợp lệ

🤖 Agent Loop (Chat AI)
Read-only agent — An toàn bởi thiết kế
Token minted với read scopes. MCP server lọc tools/list theo scope → model không bao giờ được đề xuất tool ghi. Không cần round-trip xác nhận.
🔄 Loop
Model → Tool call → Result → Model → dừng khi không cần tool. Max 20 history turns.
📏 Budget
MAX_TOOL_RESULT_CHARS = 8000 — giới hạn context bloat (mô tả dir, base64…).
🧠 Model
core:text2text:chatwithtools — Nextcloud model, tool-calling capable.
🧹 Cleanup
ExpireAgentConversationsJob — xóa transcript 30 ngày tuổi.

🖼️ Image Mode

🔄 Background Sync & Indexing
📡 SyncEventListener
Lắng nghe sự kiện thay đổi → gửi webhook đến MCP server để re-index realtime.
🔗 Webhook Presets
File created/updated/deleted, SystemTag MapperEvent, Deck card events → vector index update.
📊 Vector Sync Status
GET /api/vector-status — kiểm tra vector sync có đang bật không.
🧹 SweepJob
SweepSummaryScratchJob — dọn dẹp trang tóm tắt bị bỏ quên.
  • Webhook events: NodeCreatedEvent, NodeWrittenEvent, BeforeNodeDeletedEvent, MapperEvent (system tag), Deck events
  • Fallback: Khi webhook không hỗ trợ (Contacts, Calendar) → dùng polling scanner (CardDAV sync-token)
  • Credential: McpTokenMinter mint JWT short-lived từ Nextcloud session → OIDC (internal/external IdP)

⚙️ Cấu hình chính
  • mcp_server_url — Địa chỉ MCP Server (mặc định: http://localhost:8000)
  • mcp_webhook_secret — Shared secret cho webhook ingress
  • astrolabe.agent.enabled — Bật/tắt Agent Chat (admin)
  • astrolabe.visualization.enabled — Bật/tắt Vector Visualization (admin)
  • astrolabe.sources.enabled — Các nguồn dữ liệu được phép (admin)
  • user_disabled_search_sources — User thu hẹp nguồn tìm kiếm (JSON)
  • shareapi_default_permissions — Quyền mặc định khi tạo share
