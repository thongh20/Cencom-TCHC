👥 Thứ bậc tài khoản (4 cấp)
🏢 Super Admin
Chủ sở hữu instance. Toàn quyền truy cập mọi cài đặt, quản trị viên cấp cao nhất. Được xác định qua nhóm admin.
Toàn quyền
👔 Sub-Admin (Quản trị viên phân cấp)
Quản lý người dùng trong nhóm được phân công. KHÔNG truy cập cài đặt toàn hệ thống. Được cấu hình qua subadmin groups.
Hạn chế
👤 User (Người dùng)
Tài khoản cá nhân bình thường. Có quyền truy cập files, calendar, share… trong phạm vi cá nhân + các group share.
Cá nhân
👁️ Guest (Khách)
Truy cập qua public link (đã xác thực hoặc không). Phân quyền qua share permissions (READ/CREATE/UPDATE/DELETE/SHARE).
Public link

🛡️ Middleware kiểm soát truy cập
🔒 RequireAdmin
Chỉ Super Admin mới truy cập được. Dùng cho các trang cài đặt toàn hệ thống.
👥 SubAdminRequired
Chỉ SubAdmin (quản lý nhóm) mới truy cập. Dùng cho quản lý user trong nhóm. → SubadminMiddleware.php
🌍 NoAdminRequired
Bỏ kiểm tra admin — cho phép User/Guest truy cập. Dùng cho API public share, chat…
🚫 NoSubAdminRequired
Bỏ kiểm tra sub-admin — cho phép cả admin và user truy cập.
🛑 BruteForceProtection
Chặn sau N lần đăng nhập sai. Giới hạn rate: UserRateLimit (ví dụ: 20 req/10 phút).
🔐 AuthorizedAdminSetting
Thuộc tính trên method cho phép SubAdmin truy cập cài đặt này (miễn là họ thuộc nhóm được ủy quyền).

📤 4 loại Share trong Nextcloud
👤
User Share
Chia sẻ trực tiếp với 1 người dùng. Owner quản lý toàn bộ.
👥
Group Share
Chia sẻ với cả nhóm. Recipients: tất cả member trong group.
🔗
Link Share (Public)
Link công khai. Cài đặt: password, expiration, publicUpload, mail.
🌐
Remote (Federated)
Chia sẻ qua server khác. Cloud Federation API. Server-to-Server.
🔍 Quyền quản lý share (Share API Logic)

File: ShareAPIController.php

canEditShare($share)
✅ Owner file ($shareOwner === userId) → TRUE
✅ Người tạo share ($sharedBy === userId) → TRUE
❌ Người khác → FALSE (chỉ đọc)
canDeleteShare($share)
✅ Owner/người tạo → TRUE
✅ Recipient share type=User & sharedWith=me → TRUE (unshare)
❌ Các trường hợp khác → FALSE
canDeleteShareFromSelf($share)
⚠️ Group/Room/Deck share → KHÔNG xóa toàn bộ (chỉ gỡ self)
⚠️ Single file share → KHÔNG xóa (dùng cách riêng)
⚠️ File permissions = 0 → KHÔNG truy cập được

⚙️ Cấu hình quyền chia sẻ (config.php)
  • shareapi_default_permissions → Quyền mặc định khi tạo share (31 = tất cả)
  • shareapi_allow_public_upload → Cho phép upload qua public link
  • shareapi_allow_mail_notification → Gửi email khi share
  • shareapi_allow_public_notification → Gửi email công khai
  • shareapi_allow_socialshare → Chia sẻ ra mạng xã hội
  • shareapi_max_autocomplete_results → Giới hạn gợi ý khi share (mặc định 25)
  • shareapi_show_tags → Hiển thị tags khi chọn file chia sẻ
  • sharing.minSharePathLength / sharing.maxSharePathLength → Độ dài đường dẫn share
  • auth.bruteforce.maxAttempts → Số lần đăng nhập sai tối đa
  • shareapi_default_expire_date → Ngày hết hạn mặc định
  • shareapi_expire_after_n_days → Số ngày hết hạn

📜 Quy tắc tạo Share (Validation Rules)
  • Share bắt buộc phải có READ hoặc CREATE
  • Nếu đặt UPDATE hoặc DELETE → bắt buộc phải có READ
  • File permissions = 0 → không truy cập được
  • Single file share → không được xóa (dùng unshare thay vì delete)
  • Link share có thể đặt password + expiration date + publicUpload
  • Enforced password → Admin có thể bắt buộc đặt password cho mọi link share
  • Enforced expiration → Admin có thể bắt buộc ngày hết hạn
