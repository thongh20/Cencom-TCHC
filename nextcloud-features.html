🔄 Cách hoạt động — Luồng dữ liệu chính
1. Người dùng truy cập qua HTTP/HTTPS → PHP-FPM → index.php (routing)
2. Core xử lý xác thực (user/session/token) → phân quyền (người/nhóm/circle)
3. Request được chuyển đến app tương ứng (Files, Calendar, Talk…) qua routing.xml
4. App tương tác với CSDL (MySQL/PostgreSQL) qua OCS API / DB layer
5. File upload/download đi qua Filesystem abstraction (mount points → local/external storage)
6. Sync clients dùng WebDAV PROPFIND/MKCOL/PUT để đồng bộ
7. Talk mở WebSocket + WebRTC peer connections qua signaling server
8. Cron (định kỳ) chạy OCR, email fetch, background jobs
9. Federation proxy share requests giữa các instance qua REST
10. External Storage kết nối tới S3/FTP/WebDAV proxy trong background
