2. Danh sách Tính năng Chi tiết

2.1 💬 Chat nội bộ phân quyền các cấp

#Tính năngMô tảƯu tiên
1.1Chat phòng banTạo room chat theo phòng ban (group-based). Chỉ thành viên phòng mới vào được.Cao
1.2Chat liên cấpChat giữa cấp quản lý và cấp dưới, mỗi cấp thấy nội dung khác nhau (privacy per-level).Cao
1.3AI trợ lý trong chat@ai trong chat → AI tìm tài liệu liên quan trả lời. Tích hợp MCP server.Trung bình
1.4Tìm kiếm lịch sử chatSemantic search toàn bộ lịch sử chat theo ngữ cảnh.Trung bình
1.5Tin nhắn hết hạnTin nhắn tự ẩn sau X ngày theo cấu hình. Workflow Engine.Thấp

2.2. 📞 Gọi điện AI hỗ trợ theo từng người dùng

#Tính năngMô tảƯu tiên
2.1Tổng đài AIAsterisk + API: gọi vào → AI đọc profile → tra cứu tài liệu → phản hồi bằng giọng nói.Trung bình
2.2Hỗ trợ cá nhân hóaAI biết quyền truy cập của từng user → chỉ trả lời đúng tài liệu được phép xem.Cao
2.3Nhắc cuộc họp qua giọng nóiAI gọi điện nhắc cuộc họp dựa trên Calendar trước 30/15/5 phút.Trung bình
2.4Xác thực cuộc gọiAI xác minh danh tính qua số điện thoại → cấp quyền truy cập tài liệu bằng giọng nói.Thấp

2.3 ⏰ Cảnh báo văn bản hết hạn

#Tính năngMô tảƯu tiên
3.1Gắn ngày hết hạnCustom metadata field `expiration_date` cho mỗi file/văn bản.Cao
3.2Cảnh báo nhiều cấp30 ngày → email → 7 ngày → email + push → hết hạn → tự khóa file.Cao
3.3Dashboard giám sátTrang quản trị hiển thị văn bản sắp hết hạn theo phòng ban.Cao
3.4Phê duyệt gia hạnWorkflow: hết hạn gần → request phê duyệt → manager chấp nhận → gia hạn.Trung bình
3.5Tự động lưu trữHết hạn → tự move file vào "archived" + thông báo owner.Thấp

2.4 🧨 AI Tích hợp (Astrolabe/MCP)

#Tính năngMô tảƯu tiên
4.1Tìm kiếm ngữ nghĩaTìm văn bản bằng ngôn ngữ tự nhiên. Đã có sẵn (SemanticSearchProvider).Cao
4.2Tóm tắt tài liệuUpload tài liệu dài → AI tóm tắt 5 điểm chính. SummaryService.Cao
4.3Hỏi đáp tài liệu (Q&A)Nhập câu hỏi → AI trả lời trích dẫn nguồn từ tài liệu.Cao
4.4Phân loại tự độngAI tự gắn tag: hợp đồng, báo cáo, quy định.Trung bình
4.5Chunk viewerXem xét từng phần tài liệu lớn, AI phân tích từng chunk.Trung bình

6. Rủi ro & Giải pháp khắc phục

Rủi roMức độXác suấtGiải pháp
MCP server không ổn định / downtimeCaoCaoHTTP 503 graceful degradation đã triển khai. Cache status cục bộ. Frontend hiển thị banner rõ ràng.
Thiếu tài nguyên tính toán cho AI (GPU/CPU)CaoTrung bìnhSử dụng cloud GPU cho MCP server. Rate limiting trên API.
Vector DB quá tải khi số tài liệu tăngTBTrung bìnhElasticsearch cluster. Index chia nhỏ. Batch indexing.
Bảo mật dữ liệu (chat, tài liệu nhạy cảm)CaoTrung bìnhEncryption at rest + in transit. ACL strict per-user. Audit log.
Người dùng không chấp nhận chat AITBThấpCho phép tắt AI trong chat. AI hỗ trợ, không thay thế con người.
Tích hợp Asterisk phức tạpTBTrung bìnhPilot với 1 user trước. Dùng Asterisk ARI REST API.
Trễ tiến độ giai đoạnTBTrung bìnhReview sprint 2 tuần/lần. Feature freeze mỗi giai đoạn.
